## 🚀 How to Run Locally

### Option 1: Directly Open in Browser
Double-click `index.html` or right-click and choose **Open With > Google Chrome** (or your preferred browser).

### Option 2: Using Python's Built-in Server
Open your terminal inside this directory and run:
```bash
# Python 3
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Option 3: Using VS Code Live Server
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Click **"Go Live"** in the bottom status bar.

## 🌐 Deploying to GitHub Pages (Free)

1. Initialize a git repository and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Keerthana SR portfolio"
   ```
2. Create a repository on GitHub (e.g. `keerthanasr.github.io` or `portfolio`).
3. Link and push your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub, navigate to **Settings > Pages** and set branch to `main` and folder to `/ (root)`.
5. Your portfolio will be live at `https://YOUR_USERNAME.github.io/portfolio/`!
